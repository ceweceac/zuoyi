# 提示词优化模块（独立子系统）

> 这是 qa-bot 里一个**独立于 QA 客服**的功能模块。用户发创作类 prompt，
> 机器人帮优化成更专业的版本。本文讲清它的边界、构成、与 QA 客服的隔离。

## 一、为什么要独立

机器人有两件不同的事，**不该混**：
- **QA 客服**：被动答问题（"怎么充值""视频为什么失败"）——精确匹配知识库
- **提示词优化**：帮用户改创作 prompt（"白衣剑客站桃花树下"→补全专业描述）——LLM 创造性优化

混在一起的代价（实测）：用户问"逆光怎么打"曾被无关客服QA"模板面板怎么用"抢命中。
所以做了数据隔离 + 功能模块化。

## 二、模块构成（全部独立）

| 组成 | 文件 | 作用 |
|---|---|---|
| 识别+优化逻辑 | `services/prompt_optimizer.py` | 判断是否 prompt、分场景优化 |
| 专业素材库 | `services/prompt_materials.json` | 45条官方光影/运镜/情绪表述 |
| 开关配置 | `config.py: prompt_optimize_enabled` | 独立开关 |
| 流程接入 | `pipeline.py` 1.9 层 | KB匹配前的独立分支 |
| KB模板（可选查） | qa_item 中 category="提示词模板" 的45条 | 用户也能直接问"逆光提示词怎么写" |

## 三、与 QA 客服的隔离（关键）

**数据层隔离**（`matcher.py`）：客服问答匹配时**排除** category="提示词模板" 的条目。
即：用户问客服问题，永远不会召回到提示词模板；反之提示词优化走自己的分支。

```
用户消息
  ├─ 像创作prompt(够长+创作词+非疑问) → prompt_optimizer 优化分支
  └─ 普通问题 → QA客服匹配(已排除提示词模板) → 精确答案/转人工
```

## 四、质量保障（三重）

1. **分场景**：识别角色/视频镜头/产品广告，套对应专业标准
2. **标杆示例**：每场景给一条 DramaTV 风格的"输入→优化后"示范
3. **专业素材注入**：命中光影/运镜/情绪概念时，注入官方表述（如"伦勃朗布光"→
   官方的"45度照亮左脸、颧骨三角光斑"），避免 LLM 自编

## 五、怎么维护

- **加新的专业素材**：编辑 `prompt_materials.json`（概念名:官方描述），重启生效
- **调识别松紧**：`prompt_optimizer.py` 的 `looks_like_prompt`（当前从严，0误判优先）
- **加新场景**：`_SCENES` 字典加一类（标准+示例）
- **补KB模板**：走 kb-ingest，导入时 category 填"提示词模板"，自动隔离

## 六、边界（不做什么）

- **不做独立服务/进程**：调用量小，单体内一个模块足够，拆服务是过度设计
- **不破坏客服底线**：识别从严，宁可漏判（用户加"优化提示词:"前缀显式触发），
  绝不误把普通问题当 prompt 乱改
- **不和模型计费/掺水检测扯上**：那是另一套系统
