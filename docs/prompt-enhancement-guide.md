# 客服 Prompt 增强模板（粘贴到管理后台 /settings）

> 适用于 qa-bot 项目。请按你的实际业务**替换里面的占位符**（如 `<你的产品>`、人名等）。
> 改完后保存即可生效（[llm.py:23](backend/app/services/llm.py#L23) 5 秒节流后自动 reload）。

---

## 1️⃣ 补 `product_background`（最高优先级）

**作用**：给 LLM 业务全貌，避免它只会机械匹配 QA 条目。

**结构**：每段一个产品/模块，写它的核心运行原理 + 关键术语 + 反常识结论。

### 模板（按你实际业务改）

```
【公司业务概览】
我们是<部门/公司名>，主要做<业务方向，如：AIGC 视频/图片生成、企业内部系统、电商运营等>。
内部团队大致分：产品/技术/审核/运营/财务/人事。
用户多为公司内部员工，常见问题集中在：内部工具使用、流程报销、考勤、IT 协助、产品功能咨询。

【<产品名 1> 关键原则】
- <用 1-3 句话描述这个产品的核心机制，不超过 200 字>
- <关键术语：xxx = yyy，避免 LLM 自己脑补名词意思>
- <反常识结论：用户经常误以为 X，实际是 Y。例如：
  "卡人脸的根因是视频没过素材库预审，不是识别到了某个人，
   信任锚点是素材 ID，不是人脸 / 声音 / 身份"。>

【<产品名 2> 关键原则】
（同上结构）

【通用流程原则】
- 报销：先 OA 提交 → 主管审批 → 财务复核 → 打款。任何超流程的请求都让用户走 OA。
- 请假：年假/事假/病假/调休都在 OA「假期申请」里，3 天以上需部门负责人审批。
- IT：硬件故障 / 账号问题 / 网络问题 → 钉钉群「IT 支持」或工单系统。
- 涉及金钱、合同、人事敏感事项 → 一律不要在群里讨论，引导用户私聊 HR 或财务。

【绝对边界】
- 涉及"领导"、"内部代号"、"未发布产品名"等敏感词 → 立刻转人工（已有红线机制）
- 不要给出任何法律意见、医疗建议、投资建议
- 不要替用户做决策，只提供事实和流程指引
```

### 怎么填会效果最好

1. **不要超过 1500 字**：太长 LLM 会忽略
2. **写"反常识结论"而不是"百科描述"**：让 LLM 学到你团队的真实判断
3. **写"反例 → 正例"**：参考 `bot_persona` 里你写的"❌/✅"格式
4. **加 1-2 个真实业务场景的"原则"**：比如 "用户问 X 类问题时，先判断是不是 Y，是的话走 Z 流程"

## 2️⃣ 重写 `contact_routing`（必须改）

**作用**：[pipeline.py:380 _pick_handler()](backend/app/services/pipeline.py#L380) 按用户问题的关键词命中，挑出最相关的真人，告诉用户找谁。

**严格格式**：每行一条，**必须有冒号**（中英文都行），冒号前是关键词列表（用 `/`、`、`、`,` 分隔），冒号后是联系方式。

### 模板（替换成你公司的真实人和群）

```
图片生成 / 视频生成 / 模型问题 / Seedance / Seedream：钉钉找张三，或钉钉群「产品支持」
账号 / 登录 / 充值 / 积分 / 权限：钉钉找李四
报销 / 发票 / 差旅 / 财务：钉钉找王五，或钉钉群「财务咨询」
请假 / 调休 / 年假 / 考勤 / OA：钉钉找赵六（HR），或钉钉群「人事咨询」
IT / 电脑 / 网络 / 打印机 / 账号锁定：钉钉群「IT 支持」
Bug 反馈 / 系统异常 / 加急工单：钉钉群「技术响应」
合规 / 法务 / 合同 / 授权：钉钉找孙七
其他 / 我不知道找谁：钉钉群「全员答疑」
```

### 命中机制（必看）

- 用户问"我视频生成被卡了" → 命中 "视频生成"+"卡" 关键词 → 匹配第 1 行 → 告诉用户找张三
- 用户问"工资啥时候发" → 没命中任何关键词 → **fallback 用第一行**

**重要**：把"兜底通用条"放**最后一行**！第一行必须是命中频率最高的具体场景，因为没命中时第一行会被默认挑出来（[pipeline.py:398](backend/app/services/pipeline.py#L398)）。

### 兜底话术也要看 escalate_user_reply

[pipeline.py:411](backend/app/services/pipeline.py#L411) 的 `escalate_user_reply` 模板默认是：
```
这个我帮你转给 {handler}，稍后会联系你哈～
```

`{handler}` 会被替换成你 contact_routing 行里**冒号后的内容**。所以冒号后写"张三，或钉钉群「产品支持」"是 OK 的 — 替换进话术后通顺。

## ⚙️ 应用步骤

1. 浏览器开 `http://localhost:8080/settings`（用 admin/admin123 登录）
2. 找到「业务背景与核心原则」框 → 粘贴你定制好的 `product_background`
3. 找到「场景联系人路由」框 → 粘贴你定制好的 `contact_routing`
4. 点保存
5. 等 5 秒（[llm.py:_RELOAD_INTERVAL = 5.0](backend/app/services/llm.py#L17)），下一条用户消息就生效
6. 自己用钉钉私聊机器人测试：
   - 问个新问题验证 LLM 兜底带不带业务背景的味儿
   - 故意问个根本不在 KB 的（"我们 CEO 是谁"）触发转人工，看 `{handler}` 替换出来对不对
